# vnds-test

Source: [ajusa/VNDS-TEST](https://github.com/ajusa/VNDS-TEST) — "A simple novel
to test all VNDS functionality," by the author of the upstream ajusa/VNDS-LOVE
engine this project forks. Used here as Phase 0 item 0.4's smoke-test content
(per `VN3DS-spec.md` §16 and `GAME-PLAN.md`): a real, non-trivial VNDS script
to validate the interpreter against labels/goto, global variables with
interpolation, colored text escape codes, a multi-option choice, auto-advancing
text, long-text word-wrap, background transitions, multi-position sprites, and
sound/music with loop and cutoff behavior.
